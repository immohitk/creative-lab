# C02 — Creative Lab Clock Acceptance Criteria

## Clock Behaviour
- [ ] Time uses the system's local time.
- [ ] Seconds update correctly.
- [ ] Date and weekday are correct.
- [ ] 12-hour mode displays AM/PM correctly.
- [ ] 24-hour mode displays the expected hour range.
- [ ] Switching formats updates the display correctly.
- [ ] Date changes are reflected correctly.

## Interface
- [ ] Dark and light themes work.
- [ ] Layout adapts to mobile and desktop sizes.
- [ ] Controls have accessible names.
- [ ] Keyboard focus is visible.
- [ ] Text and controls have sufficient contrast.

## Web Version
- [ ] Runs in a browser.
- [ ] Does not require a backend.
- [ ] Clock logic can be tested independently.

## Windows Desktop Version
- [ ] Opens in its own independent Electron window.
- [ ] App name is Creative Lab Clock.
- [ ] Window controls work as intended.
- [ ] Electron security settings are appropriate.
- [ ] Packaged app runs without a development server.

## Release
- [ ] Automated tests pass.
- [ ] Windows installer builds successfully.
- [ ] Installation, launch and uninstallation are verified.
- [ ] README and screenshots are complete.
- [ ] No unrelated changes or generated binaries are committed.
- [ ] Final GitHub push succeeds after all checks pass.
